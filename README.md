# 🎓 Edulinker

Edulinker is a full-stack MERN-based e-learning platform designed to provide a modern and interactive learning experience. The platform enables students to explore courses, register securely, manage their profiles, and interact with educational content through a responsive and user-friendly interface.

Built with the MERN stack, Edulinker demonstrates complete frontend and backend integration, secure authentication, RESTful APIs, and MongoDB database connectivity. The project follows a modular architecture, making it scalable and easy to maintain.

## ✨ Features

- 🔐 JWT-based User Authentication
- 👨‍🎓 Student Registration & Login
- 👤 User Profile Management
- 📚 Browse and Explore Courses
- 🏷️ Course Categories
- 👨‍🏫 Teachers Section
- 📝 Blog Section
- 📞 Contact Form with Backend Integration
- 📱 Fully Responsive UI
- ⚡ Fast Performance with React & Vite
- 🌐 RESTful API using Express.js
- 🍃 MongoDB Database Integration
- 🔒 Password Encryption using bcrypt
